# @kasap/stale-branch-cleaner

A CLI that inspects a local git repository, lists every local and remote-tracking
branch, and classifies each one as stale based on merge status and how long it's
been since the last commit.

**This tool never deletes anything itself.** It only ever reads git state
(`git for-each-ref`, `git branch --merged`, `git log`, `git show-ref`). If you ask it
to generate a delete script, it *writes a plain shell script to disk* for you to read
and run yourself — no code path in this package calls `git branch -d/-D` or
`git push origin --delete` for real.

## How staleness is decided

For every branch other than the main/base branch itself:

- **merged** — is the branch merged into the main branch? (real check via
  `git branch --merged` / `git branch -r --merged`)
- **days since last commit** — `(now - last commit timestamp) / 86400`, via
  `git log -1 --format=%ct <branch>`

A branch is **stale** if:

- it's **merged** and `daysSinceLastCommit > --merged-days` (default **30**), OR
- it's **unmerged** and `daysSinceLastCommit > --unmerged-days` (default **90**)

Unmerged branches get a larger default threshold than merged ones, since an unmerged
branch might still be active work-in-progress — the tool is more conservative about
flagging those. The comparison is strictly greater-than: a branch sitting exactly at
the threshold is not flagged.

The main branch defaults to `main`, and is auto-detected: if `main` doesn't exist
locally, the tool falls back to `master`. Pass `--main <branch>` to override.

## Usage

```bash
# From within a repo, using defaults (main branch auto-detected, 30/90 day thresholds)
stale-branch-cleaner

# Point at a specific repo and main branch
stale-branch-cleaner --repo /path/to/repo --main develop

# Use custom thresholds (in days)
stale-branch-cleaner --merged-days 14 --unmerged-days 60

# Also write a reviewable shell script with delete commands for every stale branch
stale-branch-cleaner --generate-delete-script ./delete-stale-branches.sh
```

Example report output:

```
Main branch: main

BRANCH               MERGED  DAYS SINCE COMMIT  STALE
--------------------------------------------------------
old-feature           yes     45.2                STALE
origin/dead-thing      no     210.0               STALE
in-progress-wip        no     40.1
main-hotfix           yes     3.0

2 of 4 branch(es) flagged as stale.
```

### Generating a delete script

Passing `--generate-delete-script <path>` writes a `bash` script containing one
commented block per stale branch, e.g.:

```bash
#!/usr/bin/env bash
set -euo pipefail

# Generated by @kasap/stale-branch-cleaner.
# Review every command below before running this script - nothing here
# has been executed automatically.
#
# Local branches use `git branch -d`, which refuses to delete a branch
# that is not fully merged. If you really want to force-delete an
# unmerged local branch, manually change that line's `-d` to `-D`.

# old-feature - merged into main, 45.2 days since last commit
git branch -d old-feature

# origin/dead-thing - NOT merged into main, 210.0 days since last commit
git push origin --delete dead-thing
```

- Local branches get `git branch -d <name>` (git's own safe delete — it refuses to
  delete an unmerged branch). If you want to force-delete an unmerged local branch,
  edit that line and change `-d` to `-D` yourself.
- Remote-tracking branches (`origin/<name>`) get `git push origin --delete <name>`,
  with the `origin/` prefix stripped.

**Nothing in this script is run automatically — you always run it yourself, after
reading it.**

## CLI options

| Flag | Default | Description |
| --- | --- | --- |
| `--repo <path>` | `process.cwd()` | Path to the local git repository |
| `--main <branch>` | `main` | Main/base branch (falls back to `master` if `main` doesn't exist) |
| `--merged-days <n>` | `30` | Staleness threshold (days) for merged branches |
| `--unmerged-days <n>` | `90` | Staleness threshold (days) for unmerged branches |
| `--generate-delete-script <path>` | — | Also write a reviewable delete script to this path |

No environment variables are required — this is a pure local git tool.
